# Behzad Najafizad — Professional Knowledge Base

## Purpose

این پایگاه دانش، مرجع حرفه‌ای و قابل توسعه برای شناخت شیوه کار، تخصص، معماری فکری و روش تعامل **Behzad Najafizad** با LLMها و Agentها است.

این پایگاه دانش به دو حوزه اصلی تقسیم می‌شود:

1. **Software Engineering & Full-Stack Development**
2. **Infrastructure, Networking & IT Systems**

هدف این نیست که صرفاً یک رزومه ایجاد شود. هدف، ایجاد یک **Professional Context** پایدار است تا هنگام شروع یک پروژه، حل یک مسئله یا همکاری با یک LLM/Agent، نیاز به بازتعریف مداوم پیش‌زمینه، معماری، استانداردها و شیوه کار وجود نداشته باشد.

---

## How an LLM / Agent Should Use This Knowledge Base

هنگام دریافت یک کار جدید:

1. ابتدا حوزه کار را مشخص کن.
2. فقط Context مربوط به همان حوزه را در اولویت قرار بده.
3. در صورت وجود وابستگی بین دو حوزه، Context حوزه دوم را نیز بررسی کن.
4. قبل از پیشنهاد تغییر، محدودیت‌ها و معماری موجود را بررسی کن.
5. Facts، Preferences، Constraints، Assumptions و Recommendations را از یکدیگر تفکیک کن.
6. اگر اطلاعات کافی برای تصمیم‌گیری وجود ندارد، خلأ اطلاعاتی را صریحاً اعلام کن.
7. از بازطراحی یا تغییر معماری صرفاً به دلیل تفاوت با الگوهای مدرن خودداری کن.
8. هدف، حل مسئله در معماری واقعی موجود است؛ نه تولید یک نمونه ایده‌آل مستقل از Context.
